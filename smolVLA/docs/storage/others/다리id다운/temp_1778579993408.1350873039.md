## 📋 액추에이터 종류

Berkeley Humanoid Lite는 두 가지 액추에이터를 사용해요:

| 액추에이터 | 사용 모터 | 모터 직경 | 펌웨어 프로파일 | 용도 |
|---|---|---|---|---|
| **6512** | MAD M6C12 150KV | **68mm** (큼) | `MOTORPROFILE_MAD_M6C12_150KV` | 토크 큰 관절 (hip, knee, shoulder 등) |
| **5010** | MAD 5010 EEE V2.0 110KV | **53mm** (작음) | `MOTORPROFILE_MAD_5010_110KV` | 토크 작은 관절 (ankle, elbow, wrist 등) |

**전체 로봇 사용량**:
- 6512 액추에이터: 총 10개 (다리 8개 + 팔 2개)
- 5010 액추에이터: 총 12개 (다리 4개 + 팔 8개)

## 📊 한 눈에 보는 요약

### CAN ID 규칙
- **왼쪽 다리**: 홀수 (1, 3, 5, 7, 11, 13) - CAN2 버스
- **오른쪽 다리**: 짝수 (2, 4, 6, 8, 12, 14) - CAN3 버스

### 모터별 분포 (다리 12개 기준)
- **M6C12 (6512 액추에이터)**: 8개 → hip 3개 × 2다리 + knee 1개 × 2다리
- **MAD 5010 (5010 액추에이터)**: 4개 → ankle 2개 × 2다리

### 깔끔한 정리
```
[양쪽 hip 6개] + [양쪽 knee 2개] = 6512 (M6C12 150KV) ⭐ 큰 모터
              [양쪽 ankle 4개]    = 5010 (MAD 5010 110KV) ⭐ 작은 모터
```

## 🔧 펌웨어 플래싱 시 설정 값

각 보드를 플래싱할 때 `motor_controller_conf.h`에서 설정할 값:

### M6C12 모터 (8개 보드)
- **DEVICE_CAN_ID**: 해당 관절의 CAN ID (1, 2, 3, 4, 5, 6, 7, 8 중 하나)
- **모터 프로파일** uncomment:
  ```c
  #define MOTORPROFILE_MAD_M6C12_150KV   // ← 이거 활성화
  //#define MOTORPROFILE_MAD_5010_110KV
  //#define MOTORPROFILE_MAD_5010_310KV
  //#define MOTORPROFILE_MAD_5010_370KV
  ```

### MAD 5010 모터 (4개 보드)
- **DEVICE_CAN_ID**: 해당 관절의 CAN ID (11, 12, 13, 14 중 하나)
- **모터 프로파일** uncomment:
  ```c
  //#define MOTORPROFILE_MAD_M6C12_150KV
  #define MOTORPROFILE_MAD_5010_110KV    // ← 이거 활성화
  //#define MOTORPROFILE_MAD_5010_310KV
  //#define MOTORPROFILE_MAD_5010_370KV
  ```

## ⚠️ 중요 주의사항

### 1. 라벨 붙이기 💡
플래싱 끝난 보드에 **반드시 라벨을 붙이세요!** 
어느 관절용인지 적어두면 나중에 조립할 때 헷갈리지 않아요.

예시:
```
┌─────────────────┐
│ L_HIP_ROLL      │
│ CAN ID: 1       │
│ Motor: M6C12    │
└─────────────────┘
```

### 2. 실제 액추에이터 확인 🔍
이 표는 **표준 구성 기준**이에요. 실제로:
- 본인이 조립한 액추에이터가 6512인지 5010인지 확인
- 모터 직경 비교 (68mm vs 53mm)
- BOM 문서나 조립 가이드 재확인

만약 발목에도 6512를 썼다면 → 펌웨어 프로파일도 M6C12로!

### 3. CAN ID 충돌 주의 ⚡
같은 CAN 버스 안에 **같은 ID를 가진 보드가 두 개 있으면 안 돼요!**
- CAN2 버스: ID 1, 3, 5, 7, 11, 13 (모두 다름)
- CAN3 버스: ID 2, 4, 6, 8, 12, 14 (모두 다름)

### 4. 한 보드씩 진행 권장 🐢
여러 명이 동시에 작업하더라도, **각자 한 보드씩** 끝까지 플래싱하세요.
중간에 섞이면 어느 보드가 어느 상태인지 알기 어려워요.
