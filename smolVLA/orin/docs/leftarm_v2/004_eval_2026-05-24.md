### vs 003 동작 패턴 정성 비교

같은 task 에서 003 (wrist 상하반전 학습) 대 004 (wrist upright 학습) 의 동작 양상 차이가 보이는가? (시각 인식 신뢰도·도달 정확도·그리퍼 타이밍 등)

> **별 차이 없음**. task1·task2 둘 다 003 의 동작 양상과 *유사 — 명확한 패턴 분리 어려움*. 단 trial 수 적음 (각 1) — 미세 차이는 검출 한계 가능.
