### 성공 정의

| task | 성공 조건 |
|---|---|
| task1 | 인형을 잡고 테이블 **왼쪽**에 내려놓으면 성공 |
| task2 | 노란 캔을 사람에게 건네면 성공 (사람이 받을 수 있는 위치까지 도달) |

### 실패 원인 분류 (메모 시 사용)

| 분류 코드 | 설명 |
|---|---|
| `잡기 실패` | 물체를 집지 못함 |
| `오정렬` | 잡았으나 다른 곳에 놓음 (task1: 왼쪽 아닌 위치 / task2: 사람에게 미전달) |
| `동작 불완전` | 도중 정지 또는 동작이 완료되지 않음 |
| `task 혼동` | 다른 task 의 동작을 수행함 (예: task1 명령에 캔을 집으려 함) |
| `기타` | 위 분류에 해당 없는 경우 (메모에 구체 내용 기재) |

### 재시도 처리 정책

- 1회 시도당 1 trial — **재시도 없음**
- 단, 로봇 비정상 동작 (모터 오류·전원 이슈·케이블 단선 등 하드웨어 귀책) 시 **trial 무효** 처리 가능
  - 무효 처리 시 해당 행 "자유 메모" 에 `[무효 — 사유]` 표시
  - 무효 trial 은 집계 분모에서 제외 (예: 1회 무효 → 해당 그룹 분모 4)

## 종합 정성 메모

> 아래 항목을 자유롭게 기재하세요.

### 두 task 구분 응답성

두 task instruction 에 대해 로봇이 서로 다른 동작을 보이는가? task 혼동 사례가 있었는가?

> task2 가 task1 보다 *해당 task 방향 응답성 약간 ↑* — task1 은 인형 근처에서 헛스윙, task2 는 캔 방향으로 *팔 이동* 만큼은 함. 명시적 task 혼동 (task1 에 캔 잡으려 시도 등) 은 관찰 안 됨. 단 2 trial 만으로 일반화 불가.

### 6:4 편향 영향 관찰 (front:back)

학습 데이터의 front:back 비율이 6:4 (task1: front 30/back 20, task2: front 40/back 20) 인 점이 추론 성능에 영향을 주는 것으로 관찰되는가?

> 단축 — back orientation 미시도. 평가 불가. 다음 사이클에서 front:back 5:5 균형으로 데이터 수집 + 비교 권장.

### 동작 품질 정성 관찰

떨림·과도한 속도·충돌·경로 이탈·그리퍼 오작동 등 정성적 이상 징후.

> 동작 자체는 부드럽고 모터·하드웨어 이상 신호 없음 (gripper 0-10 정상 범위, 관절 각도 무리 없음). 정책 *판단력* 의 한계 — 도달 단계는 일부 가능, *집기·완료 단계* 응답성 부재.

### M2 본 학습 진입 가치 판단

아래 기준 참고 후 주관적 판단 기재.

- **50%+ 이상**: M1 잔여 100ep 수집 + M2 본 학습 (200ep) 진입 가치 명확
- **20~50%**: 데이터 추가 및 균형 보정 후 재평가 여지 있음
- **0~20%**: 데이터·하이퍼파라미터·추론 환경 중 병목 식별 후 재정렬 필요

> **0~20% 영역 확정** (단축 2/2 = 0%, 정성도 형편없음). M2 본 학습 (단순 200ep) 만으로는 가치 명확 X. **학습 방법 점검 + 데이터셋 확장 (개수 + 다양성) 후 재검증** 필요. 다음 사이클 Phase 1 에서 결정 영역:
> 1. 학습 방법 — LoRA rank·target / VLM trainable 여부 / epoch / lr·scheduler·batch
> 2. 데이터셋 확장 — M1 잔여 100ep + 다른 사람 + orientation 균형 + 위치 분포
> 3. 학습 노드 — prof_computer 그대로 vs DGX 재시도
> 4. 다음 검증 시점 — 본 사이클과 같은 정성 + 정량 측정 패턴
