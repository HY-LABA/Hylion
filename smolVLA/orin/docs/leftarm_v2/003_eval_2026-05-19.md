## 종합 정성 메모

### 두 task 구분 응답성

두 task instruction 에 대해 로봇이 서로 다른 동작을 보이는가? task 혼동 사례가 있었는가?

> **task 혼동 0건**. 7 trial 모두 instruction 에 맞는 동작 수행 (task1 = 인형 잡고 왼쪽 / task2 = 캔 사람에게 hand-over). 001·002 의 *헛스윙·instruction 무관 동작* 양상과 *극단적 대비*.

### 6:4 → 균형 편향 영향 관찰 (front:back)

003 dataset (310ep) 의 front:back 비율 영향. 002·001 대비 back orientation 개선이 관찰되는가?

> back orientation (4 trial) 도 front (3 trial) 와 동일하게 100% 성공. *분해능 제한* (각 그룹 1-2 trial) — 강한 결론 도출엔 부족. 단 적어도 *back orientation 에서도 동작 가능* 확인.

### 동작 품질 정성 관찰

떨림·과도한 속도·충돌·경로 이탈·그리퍼 오작동 등 정성적 이상 징후.

> 사용자 단축 종료 결정 = 모든 trial 정상 완료 + 추가 trial 의 정보 가치 낮다 판단 시그널. 명시 이상 징후 보고 없음.

### 5변수 종합 효과 판단

001·002 와 비교해 *데이터+학습효율+정렬 변수 묶음* 의 실질 효과가 관찰되는가?

> **결정적 효과 확정**. 001(0/2)·002(0/2) → 003(7/7) 로 *0% → 100%* 도약. 단 5변수 *조합 효과* 이지 dominant 변수 미분리 (단일 변수 ablation 미수행). 002 결과 (단일 변수 `empty_cameras` 무효) 를 고려하면 **데이터 양 110→310ep** 가 가장 큰 변수일 가능성 높음. sched_sync·bf16·batch 6 의 *학습 효율* 기여도는 추가 ablation 필요. → 다음 사이클 단일 변수 분리 검증 가치 있음.

### 학습 분포 외 robustness 신호 (본 사이클 신설 관찰)

학습 분포에서 벗어난 perturbation 에 대해 003 정책이 견디는가?

> **3 종류 perturbation 모두 견딤** (4 trial / 4 성공):
> - **로봇 각도 마늘랩 방향 조정** (trial #7, #17) — task1·task2 각 1회 성공. 시각 분포 변화 견딤.
> - **캔에 물 채움** (trial #12) — task2 mass 변화 견딤.
> - **다중 perturbation — 로봇 각도 + 조명 50% 감소** (trial #18) — task2 시각 + 광량 동시 변화 견딤. *가장 강한 perturbation* — 단일 변수 변화보다 어려운 조건임에도 성공.
>
> 단일 변수 perturbation 보다 다중 perturbation 이 *더 어려운 조건* 임에도 견디는 신호 — 003 정책의 일반화 능력 정성적 증명. 단 trial 수 적음 (4) → 통계적 robustness 측정은 별도 사이클 (확장 perturbation 매트릭스 또는 M4 본 검증) 영역.

### M4 본 학습 진입 가치 판단

아래 기준 참고 후 주관적 판단 기재.

- **50%+ 이상**: 003 접근 유효 확인 → M4 (패키징·재실행 체크리스트) 진입 준비
- **20~50%**: 부분 효과 → 추가 변수 조정 또는 데이터 보강 후 재평가

> **100% — 50%+ 영역 명확 도달**. **M4 (패키징·재실행 체크리스트) 진입 합리적**. 단 trial 수 적음 (7) 으로 *통계 신뢰도 제한* — 다음 사이클에서 더 큰 분포 변화 검증 또는 단일 변수 ablation 우선순위 결정은 `/wrap-spec` 단계 reflection 으로 위임.
