# NUC 배터리 전원 연결 가이드

> Hylion 프로젝트 전원부 — NUC를 배터리로 구동하는 절차
> 작성일: 2026-05-20
> 대상 장비: NUC (Beelink Mini S12, Intel N95, host `laba-desktop`)
> 함께 볼 문서: [LTC3780_AT-01_초기설정_및_사용가이드.md](LTC3780_AT-01_초기설정_및_사용가이드.md) — 승강압기 설정

---

## 1. 목적 / 개요

NUC를 AC 어댑터(벽 콘센트) 대신 **LiPo 배터리**로 구동하기 위한 결선·설정 절차.

- NUC 전원 정격: **DC 12V / 3A / 36W** (배럴 잭 입력)
- 배터리는 12V보다 높은 전압(4S 14.8V / 6S 22.2V)이므로, **DC-DC 승강압기로 12V로 낮춰** 공급한다.
- AC→DC 어댑터가 하던 일을 "배터리 + 승강압기"가 대신한다.

---

## 2. 시스템 구성도

```
[배터리]──XT60──[퓨즈박스]──14AWG──[LTC3780]──[배럴플러그]──[NUC]
 4S 14.8V        6채널 분배        승강압기      중심핀 +     DC 12V 잭
 (or 6S 22.2V)   NUC채널 5A퓨즈    12.0V 출력    슬리브 −
```

전원 흐름: **배터리 → 퓨즈박스 → 승강압기 → 배럴 플러그 → NUC**

- 퓨즈박스: 입력 1쌍 → 출력 6채널 병렬 분배. NUC는 그중 한 채널 사용.
- 승강압기(LTC3780): 배터리 전압을 12.0V로 변환.

## 4. Phase 0 — 사전 검증 (연결 전 필수)

배터리 결선에 들어가기 전에 **NUC가 진짜로 원하는 전압·극성**을 확인한다.

1. **NUC 정품 어댑터 실측** — 어댑터를 벽 콘센트에 꽂고(NUC 미연결), 배럴 플러그를 멀티미터로 측정:
   - 빨강 프로브 → 플러그 중심핀(안쪽 구멍), 검정 → 바깥 슬리브
   - **+12V 근처 + 라벨 표기 일치** 확인. 중심핀이 + 극임을 기록.
2. **배럴 잭 규격 확인** — NUC 잭 외경/내경(5.5×2.5mm 계열 추정)을 확인해 배럴 플러그를 맞춘다.

> 이 단계의 측정값이 이후 모든 작업의 "정답지"다. 승강압기 출력을 여기에 맞춘다.

---

## 5. 퓨즈 선택 기준

> **정상 최대 전류 < 퓨즈 정격 < 전선 허용 전류**

- 퓨즈는 **부하**에 맞춰 고른다. 전선 허용 전류는 넘으면 안 되는 천장(상한)일 뿐.
- 전류(A) = 전력(W) ÷ **그 지점의 전압(V)**. 퓨즈는 배터리 측에 있으므로 배터리 전압으로 계산.

**NUC 채널 계산:**

| 단계 | 값 |
|------|-----|
| 부하 전력 | NUC 36W + 승강압기 변환손실 ≈ **40W** |
| 전류 (4S 14~16V 기준) | 40W ÷ 16V ≈ **2.5A** |
| 전선(14 AWG) 허용 | ~25A |
| → 퓨즈 선택 | 2.5A < 퓨즈 < 25A → **5A 블레이드 퓨즈** |

- 부하가 늘어도 **채널 퓨즈는 안 변한다** (병렬 = 각 채널 독립).
- 단 **입력 메인 라인**(배터리→퓨즈박스)은 전 채널 전류의 **합**이 흐르므로, 부하 추가 시 메인 전선·커넥터를 재검토한다.

---

## 6. 결선 순서 (★ 배터리 분리 상태에서)

1. **배터리 분리 확인** — 모든 결선은 무전원 상태에서.
2. 배터리 XT60 ↔ 퓨즈박스 입력(+/−) 연결.
3. 퓨즈박스 NUC 채널 출력 ↔ 승강압기 `IN+`/`IN−` 연결 (14 AWG).
4. 승강압기 `OUT+`/`OUT−` ↔ DC 배럴 플러그 연결 — **OUT+ → 중심핀, OUT− → 슬리브**.
5. NUC 채널에 **5A 블레이드 퓨즈** 끝까지 삽입.
6. 이 시점까지 **NUC는 연결하지 않는다.**

---

## 7. 승강압기(LTC3780) 세팅

상세 절차는 [LTC3780 가이드](LTC3780_AT-01_초기설정_및_사용가이드.md) 참조. 요약:

1. 배터리 연결 → 승강압기 입력에 배터리 전압이 들어오는지 확인.
2. **녹색 OK 램프** 점등 확인 (적색 FAULT면 왼쪽 `UV` 나사 반시계로 낮춤).
3. **CC**(가운데 나사)를 시계방향으로 충분히 돌려 전류 상한을 높게.
4. **CV**(오른쪽 나사)로 출력을 **12.0V**에 맞춤 — 멀티미터로 `OUT`/배럴 플러그에서 확인.
   - 12.0~12.1V 범위면 정상 (오차 ±0.6% 이내 허용). 무부하 12.07V → 부하 시 ~12.0V로 떨어짐.
5. **NUC 연결 전, 배터리를 다시 분리.**

---

## 8. NUC 연결 & 기동

1. 배럴 플러그 끝단을 멀티미터로 재확인 — **12.0V, 중심핀 +** (극성 절대 확인).
2. **NUC 꺼진 상태**에서 배럴 플러그를 NUC DC 잭에 연결.
3. 배터리 연결 (XT60).
4. 승강압기 **녹색 OK** 점등 확인.
5. NUC 전원 버튼 ON → 모니터로 부팅 확인.

---

## 9. 부하 연결 후 확인

NUC가 켜진 상태(부하 인가)에서:

| 확인 항목 | 정상 범위 |
|-----------|-----------|
| 배럴 플러그 전압 | 11.7 ~ 12.3V (부하 강하 포함) |
| 승강압기 LED | 녹색 OK 유지 (FAULT·CC 모드 진입 없음) |
| 부팅 | 끝까지 정상 부팅 |

- 전압이 11.5V 이하로 끌려가거나 부팅이 실패하면 → CC가 낮거나 배터리 전압이 낮음. CC를 더 올리거나 배터리 충전.

---

## 10. 전원 종료 / 차단

⚠️ NUC는 **컴퓨터**다. 켜진 상태에서 배터리를 그냥 빼면 = 데스크톱 코드를 콱 뽑는 것 → SSD·파일시스템 손상 위험.

**정상 종료 순서:**
1. NUC를 OS에서 정상 종료 — `sudo shutdown -h now` 또는 전원 버튼 **짧게** 누름.
2. NUC가 **완전히 꺼진 것 확인** (LED·팬 정지).
3. 그 다음 배터리 분리 — **XT60 커넥터 몸체를 잡고** 분리 (전선 피복 잡고 당기지 말 것).

**헤드리스(모니터 없음) 종료:**
- SSH 접속 후 `sudo shutdown -h now` (유선 `192.168.0.8` / Tailscale `100.72.117.116`)
- 또는 전원 버튼 **짧게** 누름 (Ubuntu가 정상 종료로 처리). 4초 이상 길게 누름 = 강제 차단이므로 피함.
- 꺼짐 확인: 전원 LED·팬 정지, `ping 192.168.0.8` 무응답.

**비상 차단:**
- 연기·이상 냄새·과열·FAULT 등 → 정상 종료 무시하고 **즉시 배터리 분리.**

---

## 11. 안전 체크리스트

- ☐ 배럴 극성: 중심핀 = +, 슬리브 = − (반대 연결 시 NUC 손상)
- ☐ 승강압기 출력: 무부하에서 12.0~12.1V
- ☐ 승강압기 **녹색 OK** 점등 (적색 FAULT 상태로 부하 연결 금지)
- ☐ NUC 채널에 5A 블레이드 퓨즈 정상 삽입
- ☐ 배터리 셀 전압 정상 (저전압 배터리로 시작 금지)
- ☐ NUC 연결은 항상 마지막, 종료는 NUC 먼저

## 13. 트러블슈팅

| 증상 | 원인 후보 | 조치 |
|------|-----------|------|
| NUC 안 켜짐, 배럴 전압 0V | 퓨즈 미삽입/단선, 승강압기 FAULT | 퓨즈·LED 점검 |
| NUC 안 켜짐, 배럴 전압 정상 | 배럴 극성 반대, 잭 규격 불일치 | 극성·규격 재확인 |
| 부팅 중 꺼짐 / 전압 급강하 | CC 너무 낮음, 배터리 방전 | CC 상향, 배터리 충전 |
| 승강압기 적색 FAULT | UV 임계값 > 입력전압, 배터리 저전압 | UV 나사 반시계, 배터리 점검 |
| 퓨즈박스 채널 LED 점등 | 그 채널 퓨즈 단선 | 같은 정격 새 퓨즈로 교체 + 원인 점검 |
