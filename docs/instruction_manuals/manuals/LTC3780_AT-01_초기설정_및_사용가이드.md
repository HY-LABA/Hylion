# LTC3780 (AT-01) CC-CV 오토 승강압 컨버터 — 초기설정 및 사용 가이드

> Hylion 프로젝트 전원부 부품 사용 매뉴얼
> 작성일: 2026-05-20
> 대상 부품: [BOM](../../bom.md) §5-5 — e홈메이드클럽 **AT-01 LTC3780 CC-CV 오토 승강압 컨버터**
> 용도: 배터리(4S/6S LiPo) → NUC 12V DC 전원 공급

---

## 1. 부품 개요

- LTC3780 IC 기반 **자동 승강압(buck-boost)** DC-DC 컨버터
- 입력 DC **5–32V**, 출력 DC **1–30V 가변**
- 지속 **80W** / 최대 130W, 지속 **8A** / 최대 10A
- **CC-CV**(정전류·정전압) 모드 지원
- **저전압 차단(FAULT) 보호 회로** 내장
- 크기 77×45×15mm

> "승강압"이란? 입력 전압이 출력보다 **높아도(강압)**, **낮아도(승압)** 목표 출력(12V)을 유지할 수 있다는 뜻.
> 그래서 배터리가 방전돼 전압이 떨어져도 12V를 계속 낼 수 있음.

---

## 2. 안전 경고 ⚠️

- **적색 FAULT 램프가 켜진 상태에서 부하를 연결하면 모듈이 고장납니다 (교환·반품 불가).**
- 반드시 **녹색 OK 램프 점등을 확인한 뒤** 부하를 연결할 것.
- 부하(NUC 등)를 연결하기 전, **무부하 상태에서 출력전압을 멀티미터로 12.0V에 맞춰 둘 것.**
- 극성 주의: `OUT+` / `OUT−` 를 반대로 NUC에 연결하면 NUC가 손상될 수 있음.
- 입력단(배터리 측)에는 **5A 블레이드 퓨즈**(퓨즈박스 채널)로 과전류 보호를 둘 것.

## 3. 단자 / 조절나사 구성

### 3.1 보드 배치 (입력단을 왼쪽에 두고 글자가 바로 보이게 놓았을 때)

```
        입력단(IN)              출력단(OUT)
         5~32V                  1~30V
           │                      │
     ┌─────┴──────────────────────┴─────┐
     │           LTC3780 보드           │
     │   FAULT(적색)          OK(녹색)  │
     │    [ UV ]    [ CC ]    [ CV ]    │
     └──────────────────────────────────┘
        └ 왼쪽 ─── 트리머 3개 ─── 오른쪽 ┘
```

- **입력단(IN)** = 보드 **왼쪽**, **출력단(OUT)** = 보드 **오른쪽**
- **FAULT(적색) 램프** = 왼쪽 아래, **OK(녹색) 램프** = 오른쪽 아래
- 빨강 단자 = +, 검정 단자 = −

### 3.2 나사 단자 (4개)

| 단자 | 의미 | 연결 대상 |
|------|------|-----------|
| `IN+` / `IN−` | 입력 (보드 왼쪽) | 배터리 측 (퓨즈박스 출력 채널) |
| `OUT+` / `OUT−` | 출력 (보드 오른쪽) | 부하 측 (NUC DC 배럴 플러그) |

### 3.3 조절나사 (트리머, 3개) — ★ 왼쪽부터 UV · CC · CV

보드 아래쪽에 트리머 3개가 일렬로 있고, **왼쪽부터 `UV` → `CC` → `CV`** 순서다 (2026-05-20 실물 + e홈메이드클럽 공식 자료로 확인).

| 위치 | 나사 | 저항 코드 | 역할 | 잘못 설정 시 증상 |
|------|------|-----------|------|-------------------|
| **왼쪽** | **UV** (저전압차단) | W504 (500kΩ) | 입력이 이 값보다 낮으면 차단(FAULT) | 입력전압보다 높게 설정 시 FAULT → 출력 OFF |
| **가운데** | **CC** (정전류) | W204 (200kΩ) | 출력 전류의 상한 | 0쪽이면 무부하라도 출력이 0V로 주저앉음 |
| **오른쪽** | **CV** (정전압) | W504 (500kΩ) | 출력 전압을 몇 V로 낼지 | 0쪽이면 출력 ≈ 0V |

> **W504 / W204는 기능명이 아니라 저항값 코드다.** 504 = 50×10⁴ = **500kΩ**, 204 = 20×10⁴ = **200kΩ**.
> CC만 200kΩ(W204)이라 코드로 바로 식별되고, UV·CV는 둘 다 500kΩ(W504)이라 **위치(왼쪽/오른쪽)로 구분**한다.

> ⚠️ **이 나사들은 다회전(multi-turn) 트리머다.** 한 바퀴 돌려선 거의 변화가 없고,
> 끝에서 끝까지 가려면 **20바퀴 이상** 돌려야 함. "돌려도 반응이 없다"고 느끼는 원인 대부분이 이것.

## 4. 초기설정 순서 (★ 부하 미연결 상태에서)

1. **입력 연결** — 배터리 → 퓨즈박스(5A) → 모듈 `IN+`/`IN−` 까지만 연결. 출력단은 비워 둠.
2. **입력 확인** — 멀티미터로 `IN+`/`IN−` 측정 → 배터리 전압(4S ≈ 14~17V, 6S ≈ 20~25V)이 떠야 함. 0V면 퓨즈·결선 문제부터 해결.
3. **LED 확인**
   - **적색 FAULT 점등** → 입력이 UV 임계값보다 낮다고 판단된 상태. **왼쪽 `UV` 나사**를 **반시계방향**으로 여러 바퀴 돌려 임계값을 낮춤 → 적색이 꺼지고 녹색 OK가 켜질 때까지.
   - **녹색 OK 점등** → 정상. 다음 단계로.
4. **CC 풀어주기** — **가운데 `CC` 나사**를 **시계방향으로 5~10바퀴** 돌려 전류 상한을 0에서 올려 줌. (CC가 0이면 출력이 0V로 죽음.)
5. **CV로 전압 맞추기** — 멀티미터를 출력(`OUT+`/`OUT−`)에 물고, **오른쪽 `CV` 나사**를 돌려 **정확히 12.0V**가 되게 함.
6. **입력 분리** — 설정이 끝나면 배터리를 분리한 뒤 출력단(배럴 플러그)을 결선.

## 5. 트러블슈팅 — 출력이 0V로 측정될 때

| 증상 | 원인 | 조치 |
|------|------|------|
| `IN+`/`IN−`도 0V | 퓨즈 단선 / 결선 끊김 / 배터리 방전 | 퓨즈·전선·배터리 점검 |
| 적색 FAULT 점등 | UV 임계값이 입력전압보다 높음 | `UV` 나사 반시계로 낮춤 |
| 녹색인데 출력 0V | `CC`가 0 | `CC` 나사 시계방향으로 풀기 |
| 출력이 1~2V 어중간 | `CV`가 낮게 설정됨 | `CV` 나사 시계방향으로 12.0V까지 |
| 멀티미터에 −12V 표시 | 프로브 극성 반대 | 빨강=OUT+, 검정=OUT− 로 다시 |
| 아무 변화 없음 | 다회전 트리머를 조금만 돌림 | 같은 방향으로 계속(20바퀴+) 돌려 봄 |

## 6. NUC 전원용 권장 설정값

| 항목 | 권장값 | 비고 |
|------|--------|------|
| 출력전압 (CV) | **12.0V** | NUC 정품 어댑터 실측값과 일치시킬 것 |
| 정전류 (CC) | **4~5A** | NUC 최대 약 3A보다 여유. 너무 낮으면 부팅 시 전압 강하 |
| 저전압 보호 (UV) | 4S ≈ **13.0V** / 6S ≈ **19.0V** | 배터리 과방전 1차 차단 겸용. 단 셀 전압은 별도 점검 필요 |
| 입력 퓨즈 | **5A 블레이드** | 퓨즈박스 채널에 삽입 |

> UV는 어디까지나 거친 보호장치임. LiPo 셀당 3.5V(4S=14.0V, 6S=21.0V) 이하 방전은 셀 단위로 별도 관리할 것.

## 7. 멀티미터(Fluke 179) DC전압 측정법

- 다이얼을 **`V⎓`** (V 옆 실선+점선 = DC전압)로 설정
- **빨강 프로브 → `VΩ` 단자**, **검정 프로브 → `COM` 단자**
- 측정 시: **빨강 = +**, **검정 = −**
- 배럴 플러그 측정 시: 빨강 = 중심핀(안쪽 구멍), 검정 = 바깥 슬리브 → **+12V 표시면 중심핀이 +극**
