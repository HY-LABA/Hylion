# T200으로 우리 LiPo 충전하기 — 절차 + 주의사항

작성일: 2026-05-19
담당: 인혁
대상 장비: SkyRC T200 + CNHL 6S 10000mAh / CNHL 4S 8000mAh
참고 매뉴얼: [T200_Instruction_Manual_EN_V1.20.pdf](../instruction_manuals/T200_Instruction_Manual_EN_V1.20.pdf)

## 1. 우리 장비 요약

| 항목 | 사양 |
|---|---|
| 충전기 | **SkyRC T200** · 듀얼 채널 · **채널당 100W / 0.1–12.0A** |
| 배터리 A | **CNHL 6S 10000mAh 100C** (22.2V, XT60↔XT90 변환 결합 완료) |
| 배터리 B | **CNHL 4S 8000mAh 120C** (14.8V, XT60) |

> ⚠️ **핵심 제약** — T200은 채널당 **100W 한계**. 1C(=용량과 같은 전류) 충전 시 와트 초과 → **전류를 낮춰서** 충전해야 한다.

## 2. 권장 충전 전류 (외워둘 것)

| 배터리 | 1C 이론값 | 1C 시 와트 | T200 100W 한계 | **권장 설정** | 예상 시간 |
|---|---|---|---|---|---|
| 6S 10000mAh | 10.0A | 222W (×) | ~4.0A | **3.5–4.0A** (≈0.4C) | 약 2.5–3시간 |
| 4S 8000mAh | 8.0A | 118W (×) | ~5.5A | **5.0A** (≈0.625C) | 약 1.6시간 |

> 더 높이면 T200이 자동으로 전류 떨어뜨리거나 정지함. 채널 동시 충전해도 각 채널이 독립 100W라 위 표 그대로 OK.

---

## 3. 충전 전 체크리스트

**배터리 상태**
- [ ] 외관: 부풀음(swell)·찌그러짐·변색·이상 발열 **없음**
- [ ] 셀당 전압: **3.6–3.85V** 사이 정상 (장기 보관 직후엔 3.8V)
- [ ] 셀당 전압 편차: **0.05V 이하** 권장
- [ ] 셀 하나라도 **3.0V 이하** → 충전 금지, 폐기

**환경**
- [ ] 충전기 주변 **30cm 이상 가연물 없음**
- [ ] **LiPo 안전 가방** 또는 금속·세라믹 트레이 위
- [ ] 환기 OK · 직사광선/차내/카펫/소파 위 금지

**케이블**
- [ ] 메인선(XT60)과 **밸런스 케이블(JST-XH)** 둘 다
- [ ] 6S: XT60↔XT90 변환 어댑터의 **+ / −** 육안 재확인
- [ ] 밸런스 흑선이 배터리 흑선 쪽인지 방향 확인

## 4. 연결 순서 (매뉴얼 p11)

> **충전기 측 먼저, 배터리 측 나중에. 분리는 역순.** 반대로 하면 메인선 양끝이 살아있어 단락 위험.

1. T200 전원 케이블(AC 권장) 연결 → 부팅 확인
2. **메인 충전선**의 한쪽 → T200 채널 출력 소켓 (A 또는 B)
3. **밸런스 케이블** → 같은 채널의 밸런스 소켓 (6S/4S 슬롯 맞춰서)
4. 메인 충전선 반대쪽 → 배터리 메인 커넥터
5. 밸런스 커넥터 → 배터리 밸런스 포트
6. 분리 시 **5 → 4 → 3 → 2** 역순

---

## 5. T200 조작 — LiPo Balance Charge

버튼: `BATT/PROG` · `DEC` · `INC` · `STOP` · `START/ENTER` · 채널 전환 `A/B`

1. `BATT/PROG` → **LiPo BATT** 선택 → `START/ENTER`
2. INC/DEC로 **`LiPo BALANCE`** → `START/ENTER`
3. **전류** 설정 → `START/ENTER`
   - 6S 10000mAh: **4.0A**
   - 4S 8000mAh: **5.0A**
4. **전압(셀 수) 자동 표시 확인** — `22.2V (6S)` / `14.8V (4S)` 맞는지
5. `START/ENTER` **3초 길게** → 충전 시작
6. `R: ?S  S: ?S CONFIRM` 화면 → **R(검출)과 S(설정) 같으면** `ENTER`, 다르면 `STOP` 후 케이블 점검
7. 충전 중 INC/DEC로 셀별 전압·용량·입력 전압·내부 온도 모니터링 가능
8. 완료 시 **`END FINISH`** + 비프음 (셀당 ~4.18–4.20V)

---

## 6. 보관(STORAGE) 모드 — 1주 이상 안 쓸 때 필수

LiPo는 만충(4.2V/cell)으로 오래 두면 셀 손상이 빠름. **셀당 3.8V**로 맞춰 보관.

- 메뉴: `LiPo BATT` → **`LiPo STORAGE`** → 전류 설정 → 시작
- 만충 상태면 자동 방전, 부족하면 자동 충전 → 3.8V/cell로 수렴
- 6S 만충 → 3.8V 변환 시 약 30~50분
- 시연/시험 사이 1주 이상 비면 **무조건 STORAGE**로 내려두기

---

## 7. 방전(Discharge)

T200 내부 방전 = **단 10W**라 매우 느림. 평소엔 거의 쓸 일 없음.
필요한 경우만:
- 셀 밸런스 점검용
- 폐기 전 완전 방전 (단, **셀당 3.0V까지만**, 그 이하는 자가 손상)

---

## 8. 동시 2채널 운용 주의

- A·B 채널은 **각각 독립 100W**, 합계 200W
- **AC 100–240V 사용 시**: 그냥 두 채널 풀로 OK
- **DC 12V 입력 사용 시**: 입력 전원이 최소 **16~17A 이상** 공급 가능해야 함 (200W ÷ 12V). 부족하면 `DC IN TOO LOW` 에러
- 우리 일반 작업: **AC 직결 권장**

---

## 9. 에러 메시지 대처 (매뉴얼 p29)

| 에러 | 의미 | 조치 |
|---|---|---|
| `REVERSE POLARITY` | 극성 반대 | 즉시 분리, 변환 어댑터 +/− 재확인 |
| `CONNECT ERROR / CHECK MAIN PORT` | 메인 커넥터 접촉 불량 | 다시 꽂기, 단자 상태 확인 |
| `BALANCE CONNECT ERROR` | 밸런스 커넥터 오연결 | 슬롯·방향 재확인 |
| `CELL ERROR LOW VOLTAGE` | 셀 전압 너무 낮음 | **충전 중단, 폐기 검토** |
| `CELL ERROR HIGH VOLTAGE` | 셀 전압 너무 높음 | 즉시 중단 |
| `CELL NUMBER INCORRECT` | 설정 셀 수 ≠ 실제 셀 수 | 6S/4S 설정 재확인 |
| `INT.TEMP TOO HI` | 충전기 내부 과열 | 정지·식힘, 환기/팬 확인 |
| `BATTERY HAS FULL` | 이미 만충 | 충전 불필요, 필요 시 STORAGE |
| `DC IN TOO LOW / HIGH` | DC 입력 11V↓ / 18V↑ | DC 어댑터 교체 또는 AC 사용 |

## 10. 절대 금지

1. **부풀어 오른 배터리 충전** — 즉시 격리·폐기(소금물 침수)
2. **무인 충전** — 매뉴얼 p5 1순위 경고. 시야에서 절대 떠나지 말 것
3. **밸런스 케이블 없이 LiPo 충전**
4. **1C 초과 전류** — CNHL 사양 "Allowable Fast Charge ≤ 1C"
5. **셀당 4.2V 초과 충전** — 셀 수 잘못 설정 시 발생 가능
6. **셀당 3.0V 미만 운용** — 한 번이라도 깊이 방전된 LiPo는 다음 충전 시 폭발 위험. 폐기.
7. **차량 내·직사광선 보관**

---

## 11. 화재 시

- LiPo 화재는 **물로 못 끈다** (D급 소화기 또는 모래가 정답)
- 일반 ABC 소화기는 주변 확산 차단만 가능
- 가능하면 **창밖/콘크리트 바닥**으로 던지고 멀리. 가스 유독.

---

## ⚡ 첫 충전 요약 시퀀스

1. 외관 점검 → 셀 전압 측정
2. T200에 AC 연결, 부팅
3. **충전기 측 케이블 먼저 → 배터리 측 나중**
4. `LiPo BALANCE` 모드, **6S=4.0A / 4S=5.0A**
5. R/S 셀 수 일치 확인 → 3초 길게 누름
6. LiPo 가방·금속 트레이 위, **자리 떠나지 말 것**
7. `END FINISH` → 배터리 측부터 분리
8. 바로 안 쓰면 **STORAGE 모드로 3.8V/cell** 내리고 마무리
