# Jetson 배터리 전원 연결 가이드

> Hylion 프로젝트 전원부 — Jetson을 배터리로 구동하는 절차
> 작성일: 2026-05-20
> 대상 장비: NVIDIA **Jetson Orin Nano Super Developer Kit** (엣지 추론 노드)
> 함께 볼 문서: [LTC3780_AT-01_초기설정_및_사용가이드.md](LTC3780_AT-01_초기설정_및_사용가이드.md) · [NUC연결가이드.md](NUC연결가이드.md)

---

## 1. 목적 / 개요

Jetson Orin Nano Super Developer Kit를 AC 어댑터 대신 **LiPo 배터리**로 구동하기 위한 결선·설정 절차.

- Jetson 전원 정격: **DC 7~20V (와이드 레인지)**, 커넥터 **5.5×2.5mm 배럴 잭**
- 공식/권장 어댑터: **19V / 2.37A (약 45W)**
- 배터리(4S 14.8V / 6S 22.2V)를 승강압기로 변환해 공급한다.

> **★ NUC와의 핵심 차이** — NUC는 **12V 고정**이지만, Jetson은 **7~20V 범위 어디든** 동작한다.
> 그래서 출력 전압을 한 값에 못박지 않고 범위 안에서 고를 수 있다 (§5 참조).

---

## 2. 시스템 구성도

```
[배터리]──XT60──[퓨즈박스]──14AWG──[LTC3780]──[배럴플러그]──[Jetson]
 4S 14.8V        6채널 분배        승강압기      중심핀 +     DC 7~20V 잭
 (or 6S 22.2V)   채널 5A퓨즈       19V 출력      슬리브 −     (5.5×2.5mm)
```

전원 흐름: **배터리 → 퓨즈박스 → 승강압기 → 배럴 플러그 → Jetson**

## 4. Phase 0 — 사전 검증 (연결 전 필수)

1. **Jetson 정품 어댑터 실측** (어댑터 보유 시) — 어댑터를 벽 콘센트에 꽂고(Jetson 미연결), 배럴 플러그를 멀티미터로 측정:
   - 빨강 프로브 → 플러그 중심핀(안쪽 구멍), 검정 → 바깥 슬리브
   - **+19V 근처 + 중심핀이 + 극** 확인. (어댑터가 없으면 공식 사양 19V 기준)
2. **배럴 잭 규격 확인** — Jetson 잭은 **5.5×2.5mm**. 배럴 플러그를 이 규격으로 맞춘다.

> 측정값(전압·극성)이 이후 작업의 정답지다.

---

## 5. 출력 전압 선택 — ★ Jetson 특유 (7~20V 범위)

Jetson은 7~20V 어디서든 동작하므로 승강압기 출력을 범위 안에서 고를 수 있다.

| 선택 | 값 | 장점 | 변환 모드 |
|------|-----|------|-----------|
| **권장** | **19V** | NVIDIA 공식 어댑터와 동일 — 풀 파워버짓 확실, 의심 제거 | 4S → 승압 / 6S → 강압 |
| 효율 우선 | 배터리 전압 근처 (4S면 ~15V) | 변환 손실 최소 | 4S → ≈동전압 |

- **이 가이드는 19V 기준**으로 진행한다 (단순·안전).
- LTC3780은 승강압기라 배터리가 19V보다 낮든(4S) 높든(6S) 19V를 만들 수 있다.
- ⚠️ 7V 미만·20V 초과는 금지. 범위를 벗어나면 Jetson 손상.

---

## 6. 퓨즈 선택 기준

> **정상 최대 전류 < 퓨즈 정격 < 전선 허용 전류**
> 퓨즈는 부하에 맞춰 고르고, 전류(A) = 전력(W) ÷ **배터리 측 전압(V)** 으로 계산한다.

**Jetson 채널 계산:**

| 단계 | 값 |
|------|-----|
| 부하 전력 | Jetson 최대 ≈ 45W + 변환손실 ≈ **50W** |
| 전류 (4S 14~16V 기준) | 50W ÷ 15V ≈ **3.3A** |
| 전선(14 AWG) 허용 | ~25A |
| → 퓨즈 선택 | 3.3A < 퓨즈 < 25A → **5A 블레이드 퓨즈** |

- 4S 기준 정상 전류(~3.3A)와 5A 퓨즈의 마진이 NUC보다 다소 좁다. 추론 풀부하에서 잦은 단선이 발생하면 부하 실측 후 **10A**로 재검토.
- 6S 배터리면 전류가 ~2.3A로 낮아져 5A가 한결 여유롭다.

## 7. 결선 순서 (★ 배터리 분리 상태에서)

1. **배터리 분리 확인** — 모든 결선은 무전원 상태에서.
2. 배터리 XT60 ↔ 퓨즈박스 입력(+/−) 연결.
3. 퓨즈박스 Jetson 채널 출력 ↔ 승강압기 `IN+`/`IN−` 연결 (14 AWG).
4. 승강압기 `OUT+`/`OUT−` ↔ DC 배럴 플러그 — **OUT+ → 중심핀, OUT− → 슬리브**.
5. Jetson 채널에 **5A 블레이드 퓨즈** 끝까지 삽입.
6. 이 시점까지 **Jetson은 연결하지 않는다.**

---

## 8. 승강압기(LTC3780) 세팅 — 목표 19V

상세 절차는 [LTC3780 가이드](LTC3780_AT-01_초기설정_및_사용가이드.md) 참조. 요약:

1. 배터리 연결 → 승강압기 입력에 배터리 전압이 들어오는지 확인.
2. **녹색 OK 램프** 점등 확인 (적색 FAULT면 왼쪽 `UV` 나사 반시계로 낮춤).
3. **CC**(가운데 나사)를 시계방향으로 충분히 돌려 전류 상한을 높게.
4. **CV**(오른쪽 나사)로 출력을 **19.0V**에 맞춤 — 멀티미터로 `OUT`/배럴 플러그에서 확인.
   - 18.5~19.5V 범위면 정상. 무부하 측정값은 부하 시 약간 떨어진다.
5. **Jetson 연결 전, 배터리를 다시 분리.**

> ⚠️ NUC 가이드는 12.0V, 이 가이드는 **19.0V**다. 같은 승강압기를 NUC↔Jetson 사이에 번갈아 쓸 경우 **연결 대상이 바뀔 때마다 CV를 다시 맞출 것.** 12V 설정인 채로 Jetson에 꽂아도(7~20V 범위라) 동작은 하지만, 19V 설정인 채로 **NUC(12V 고정)에 꽂으면 NUC가 손상된다.**

---

## 9. Jetson 연결 & 기동

1. 배럴 플러그 끝단을 멀티미터로 재확인 — **19.0V, 중심핀 +** (극성 절대 확인).
2. **Jetson 꺼진 상태**에서 배럴 플러그를 Jetson DC 잭에 연결.
3. 배터리 연결 (XT60).
4. 승강압기 **녹색 OK** 점등 확인.
5. Jetson 전원 버튼 ON → 부팅 확인.

---

## 10. 부하 연결 후 확인

Jetson이 켜진 상태(부하 인가)에서:

| 확인 항목 | 정상 범위 |
|-----------|-----------|
| 배럴 플러그 전압 | 18~20V (부하 강하 포함, 7~20V 범위 내) |
| 승강압기 LED | 녹색 OK 유지 (FAULT·CC 모드 진입 없음) |
| 부팅 | 끝까지 정상 부팅 |

- 추론 풀부하 시 전압이 흔들리거나 부팅·추론 중 꺼지면 → CC가 낮거나 배터리 전압 부족. CC 상향 또는 배터리 충전.

---

## 11. 전원 종료 / 차단

⚠️ Jetson은 **컴퓨터(Linux/JetPack)** 다. 켜진 상태에서 배터리를 그냥 빼면 NVMe·파일시스템 손상 위험.

**정상 종료 순서:**
1. Jetson을 OS에서 정상 종료 — `sudo shutdown -h now` 또는 `sudo poweroff`, 또는 전원 버튼 **짧게** 누름.
2. Jetson이 **완전히 꺼진 것 확인** (전원 LED·팬 정지).
3. 그 다음 배터리 분리 — **XT60 커넥터 몸체를 잡고** 분리 (전선 피복 잡고 당기지 말 것).

**헤드리스(모니터 없음) 종료:**
- SSH 접속 후 `sudo shutdown -h now` (Orin IP는 운영 네트워크 기준 — 별도 확인).
- 또는 전원 버튼 **짧게** 누름. 길게 누름(강제 차단)은 시스템이 멈췄을 때만.
- 꺼짐 확인: 전원 LED·팬 정지, `ping` 무응답.

**비상 차단:**
- 연기·이상 냄새·과열·FAULT 등 → 정상 종료 무시하고 **즉시 배터리 분리.**

---

## 12. 안전 체크리스트

- ☐ 배럴 극성: 중심핀 = +, 슬리브 = − (반대 연결 시 Jetson 손상)
- ☐ 승강압기 출력: 무부하에서 18.5~19.5V, **7~20V 범위 절대 준수**
- ☐ 승강압기 **녹색 OK** 점등 (적색 FAULT 상태로 부하 연결 금지)
- ☐ Jetson 채널에 5A 블레이드 퓨즈 정상 삽입
- ☐ 배터리 셀 전압 정상
- ☐ Jetson 연결은 항상 마지막, 종료는 Jetson 먼저
- ☐ NUC와 승강압기 공용 시 — 대상 바뀔 때마다 CV 재설정 (NUC 12V / Jetson 19V)

|------|------------------------|--------------------------------|
| 입력 전압 | **12V 고정** | **7~20V 범위** (권장 19V) |
| 배럴 잭 | 5.5×2.5mm (추정) | 5.5×2.5mm |
| 정격 전력 | 36W | 약 45W |
| 승강압기 CV 설정 | 12.0V | 19.0V |

## 15. 트러블슈팅

| 증상 | 원인 후보 | 조치 |
|------|-----------|------|
| Jetson 안 켜짐, 배럴 전압 0V | 퓨즈 미삽입/단선, 승강압기 FAULT | 퓨즈·LED 점검 |
| Jetson 안 켜짐, 배럴 전압 정상 | 배럴 극성 반대, 잭 규격 불일치 | 극성·규격 재확인 |
| 부팅·추론 중 꺼짐 / 전압 급강하 | CC 너무 낮음, 배터리 방전 | CC 상향, 배터리 충전 |
| 승강압기 적색 FAULT | UV 임계값 > 입력전압, 배터리 저전압 | UV 나사 반시계, 배터리 점검 |
| 퓨즈박스 채널 LED 점등 | 그 채널 퓨즈 단선 | 같은 정격 새 퓨즈로 교체 + 원인 점검 |
