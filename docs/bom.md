## 0. 사용법

- 부품을 추가할 때는 해당 카테고리 표의 마지막 줄에 한 줄을 추가합니다.
- `수량`과 `단가`만 채우면 `합계 = 수량 × 단가` 입니다 (수기 계산).
- 단종/대체 발생 시 `비고`에 "→ 대체품: …" 형태로 메모합니다.
- `링크`는 구매처 URL을 그대로 붙여 넣습니다 (마크다운 `[텍스트](URL)` 형식 권장).
- `담당`은 해당 부품의 발주·검수 책임자를 적습니다. 인원: **인혁 / 상윤 / 희승 / 승민 / 성래**. 공동 담당이면 `인혁·상윤`처럼 가운뎃점으로 묶습니다.
