사용자는 한양대 Biz Lab의 Hylion(하이리온) Physical AI 로봇 프로젝트 팀원. 그동안 프로젝트의 "뇌" 파트(STT, LLM, TTS, 대화 파이프라인 — 최근 커밋: Groq whisper-large-v3-turbo STT, Ollama+EXAONE 3.5 LLM, MeloTTS 데몬)만 담당해왔음. AI/소프트웨어 백그라운드.

**현재 전환점 (2026-05)**: 하드웨어 조립 단계가 임박해서 Berkeley Humanoid Lite(BHL) 하반신 작업에도 합류해야 함. BHL 도메인 지식이 전무한 상태에서 빠르게 학습 중. 기획서 v12 기준 본인 역할은 ε1(데이터·대화·통합 오너, Track A 리드)로 추정 — STT/LLM/TTS 작업 패턴과 일치.

**협업 컨텍스트**: 같은 프로젝트에서 δ2(보행 시스템 오너, Track B 리드)와 δ3(AI 인프라 오너)가 BHL/Walking RL을 주로 다룸. 본인은 이들과 공통 어휘를 갖추는 게 학습 목표지, BHL 하드웨어 전문가가 되려는 건 아님.

**커뮤니케이션 선호**: 한국어. 소프트웨어 비유로 하드웨어 개념을 다리 놓는 설명을 선호 ([[feedback-bridge-by-analogy]] 참고 가능). 구조화된 출력(섹션·표·체크리스트)을 직접 활용하는 경향.

**현재 학습 자원**: BHL 논문 + GitBook 문서 + GitHub 코드를 AI 도움받아 정리 중. 이미 [모터컨트롤러 펌웨어 플래싱 StepByStep](../docs/BHL/모터컨트롤러_펌웨어_플래싱_StepByStep.md) 같은 한국어 가이드를 본인이 작성하며 학습 중.
